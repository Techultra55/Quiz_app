# Quiz_app

**Quiz_app** is a simple and interactive quiz application built entirely in Java. This project demonstrates Java fundamentals and provides a basic template for creating quiz-based applications.

## General Information

- **Language:** Java (100%)
- **Purpose:** A console or GUI-based quiz game where users can test their knowledge on various topics.
- **Key Features:**
  - Fully implemented in Java for cross-platform use
  - Easy to extend or customize with new questions and categories
  - Great for educational use, practice, or as a programming example

## Getting Started

1. Clone the repository:
    ```sh
    git clone https://github.com/Techultra55/Quiz_app.git
    ```
2. Open the project in your favorite Java IDE (e.g., IntelliJ IDEA, Eclipse).
3. Compile and run the main class to start the quiz.
